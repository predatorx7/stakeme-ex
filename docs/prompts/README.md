agents on SMX. It is part of the [AI-use disclosure](../ai-usage.md).

[session-user-prompts.md](session-user-prompts.md) is the **verbatim export of
every human prompt** from the Claude Code session log (read this first). The
numbered files below it are short summaries; each is
**reconstructed from what the repository shows**. Text in quotation
marks is quoted verbatim from the named repo file. Everything else is a
paraphrase.
