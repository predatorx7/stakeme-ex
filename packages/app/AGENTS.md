# packages/app

The SMX backend and server-rendered exchange UI. `openapi.yaml` here is the
single source of truth for every operation and for the generated client.

Inherit the repo-wide rules from the root `AGENTS.md`. The rules below are
specific to this package.

## Layout

```
openapi.yaml            Every route, with full request limits
pg-migrate.config.ts    Plugins: pgmb (vendor SQL) + smx (sql/ + migrations/)
vite.client.config.ts   Browser bundle
sql/ddl.sql             Desired schema state (base: domains, Better Auth, helpers)
sql/queries.sql         Every PGTyped query
migrations/             Generated by `npm run migrate:plan`
src/
  index.ts              Package exports
  server.ts             Production entry (compiled): HTTP + workers
  app.ts                createApp(pg): middleware, validator, route resolver
  db.ts                 Pool factory (search_path=smx, timezone=UTC)
  consts.ts             Env-derived constants
  auth.ts               resolveViewer / requireAuth
  better-auth.ts        Better Auth with the SIWE plugin
  pgmb.ts               pgmb client singleton
  queries.ts            GENERATED by PGTyped
  routes/               One default-exported handler per operationId
  components/           TSX components (PascalCase), grouped by feature
  client/               Browser modules (index.ts boots htmx)
  worker/register.ts    pgmb consumers and sweeps
  utils/                Small helpers (kebab-case)
  types/                openapi.ts aliases, misc.ts
public/styles           App CSS, imported in `@layer app`
public/assets           Static images and fonts
scripts/                dev, start, migrate, codegen, drift check
tests/                  pglite.ts, utils.ts (bootApp), *.test.ts
```

## Markup and styling

1. Keep the DOM flat.
2. Prefer `padding` over `margin`. Space siblings with `gap`.
3. Set simple transitions, such as hover, to `0.1s`.
4. Don't draw icons. Use the `Icon` component, which renders
   `@reclaimprotocol/design/icons`. If none fits, ask.
5. Search for an existing component, CSS rule, or utility before writing one.
6. Use semantic elements (`<button>`, `<header>`, `<section>`), not `div` by
   default.
7. Escape all dynamic text (`escapeHtml`, `escapeText`, `markup`). `npm run
   check` runs the XSS scan.
8. Never hard-code a `/public/dist/...` URL. `utils/client-assets.ts` resolves
   it through the Vite manifest.
9. Name the app "StakeMe Exchange" in page titles. Don't add Reclaim branding.

## Adding a route

1. Add the operation to `openapi.yaml`. Type and bound every input
   (`maxLength`, `maxItems`, `minimum`, `enum`, `format`). Declare `security`
   and `default: ProblemResponse`.
2. Run `npm run openapi:gen --workspace=packages/app`. This writes
   `packages/client/src/types/openapi.gen.ts` and `routes.gen.ts`.
3. Add the query to `sql/queries.sql`, then run `npm run pgtyped:typegen`.
4. Write `src/routes/<OperationId>.ts(x)` with `ITypedExpressRequest<'Op'>`.
   Don't re-validate what the schema validates. A missing file returns 501.
5. Serve HTML and JSON from one handler: `shouldSendJson(req)` picks JSON.
   htmx mutations return `204` + `HX-Redirect` (`sendOrRedirect`).

Keep validation in the OpenAPI schema. It is the source of truth.

## Components

### Dialog

1. Use the `Dialog` component. Its header has a close button at top right.
2. Don't add a "Cancel" button. Put actions in the `footer` prop.
3. Don't open a dialog on a dialog. Confirm with the user first if unavoidable.

### Forms

Use `HxForm`. It puts 4xx problem details in `.form-error` and shows other
errors as a toast.

## Background work

Use pgmb. Producers publish inside the request's transaction through `req.pg`.
Register consumers in `worker/register.ts`; call `useAppSchema(pg)` first in
every handler, because pgmb leaves the connection on its own `search_path`.

## Tests

`npm test` warms a PGlite snapshot of all migrations, then runs
`tests/*.test.ts`. Boot the app with `bootApp()` from `tests/utils.ts`.

## Integrations

- Chain calls go through `chain.ts` (retry, mirror-node wait). Gas limit is
  estimate +20%. One signer process for `ORACLE_PRIVATE_KEY` at a time.
- Audit approval needs 0G Private Computer. Rules fallback only with
  `ZG_ALLOW_RULES_FALLBACK=1`. 0G Storage writes go through the outbox.
- Render real World ID (IDKit) only when configured, never simulators beside it.
- Avatars: seed Gravatar by account or creator ID, never wallet.
- UI copy: no festival words, no external design credits, run the AI-tell check.

See the root `AGENTS.md` for the full list.
